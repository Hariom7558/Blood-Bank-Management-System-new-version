

## ❓ FAQ

### Q: Do I need to install anything else?
**A:** No! Just Python 3.8+ and `pip`. Everything else is included.

### Q: Where is my data stored?
**A:** In `blood_bank.db` (SQLite database, automatically created).

### Q: Can I use MySQL instead?
**A:** Yes! See configuration in [DEPLOYMENT.md](DEPLOYMENT.md).

### Q: How do I reset the database?
**A:** Delete `blood_bank.db` and run `python app.py`.

### Q: Can I change the port?
**A:** Yes! Edit the last line in `app.py` and change port from 5000.

### Q: Is it production-ready?
**A:** Yes! Complete deployment guide in [DEPLOYMENT.md](DEPLOYMENT.md).

### Q: Can I modify the code?
**A:** Absolutely! It's designed to be customizable.
